## 阅读路径

- **第一次用 / 想了解产品**：先 [操作手册.md](操作手册.md)，再 [技术栈与概念详解.md](技术栈与概念详解.md)。
- **要写插件**：[插件开发指南.md](插件开发指南.md)（三种运行时）；写 native 核心插件再看 [核心插件示例教程.md](核心插件示例教程.md)。
- **要维护探针卡分层**：先用 [改造方案-探针卡分层Rust化.md](改造方案-探针卡分层Rust化.md) 了解已落地的 Rust 化，
  再读 [零过孔改进方案](探针卡分层-可布线零过孔改进方案.md) 了解下一步（走通率指标建议先行）。
- **要发版**：[发布流程.md](发布流程.md)；同时看仓库根 `CHANGELOG.md` 确认版本与变更。

## 状态术语

- **现行**：与当前代码一致，日常阅读以它为准。
- **已实施**：记录已经做完的改造/决策，保留作参考与复盘，不代表"待办"。
- **方案稿**：评审/规划，未改代码；落地前先对齐再动工。
