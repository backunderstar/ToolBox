# ToolBox 前端架构 — 学习导言

> 前端 = `src/`（Vue 3 + Vite(vite-plus/rolldown) + TypeScript）。
> 本文讲"前端怎么跟 Rust 宿主交互、怎么把插件界面挂进来、主题怎么切"，帮助定位源码。

---

## 1. 一句话
前端是一个 **Vue 3 单页应用**：通过 `@tauri-apps/api` 的 `invoke` 调 Rust 命令；
用 `reactive/ref` + `watch` 管理状态；视图按 `src/views/` 分页、通用部件在 `src/components/`、
逻辑/类型/IPC 封装在 `src/core/`；`src/styles/tokens.css` 是设计令牌（暗/亮主题靠 `[data-theme]`）。

---

## 2. 目录地图

```
src/
  main.ts              入口：createApp + 挂载 + 全局初始化(工作区/插件/主题)
  App.vue              外壳：布局(侧边栏/顶栏/状态栏)、视图注册、动态路由(插件导航/浮窗)
  core/                核心逻辑(与 UI 无关)
    api.ts             ★所有 invoke 封装 + 类型(与 Rust serde camelCase 一一对应)
    ipc.ts / useTauriListen.ts   invoke/事件监听工具
    plugins.ts         ★插件模块级单例 store(读取启停/状态/导航/主题)
    pluginRuntime.ts   ★插件运行时：读入口→Blob <script> 注入→统一 api 桥(call/on/log/context/nav/host)
    vault.ts           当前工作区状态(reactive，后端 workspace_* 驱动)
    navigation.ts / navPrefs.ts   侧边栏导航模型 + 持久化
    prompt.ts          通用"输入/确认"弹窗封装

    version.ts         应用版本(由 version:sync 同步)
  views/               页面级视图
    WelcomeView / OnboardingView   首启/欢迎
    FilesView          文件管理(宿主文件服务)
    InputView          ★文件输入(拖拽导入/归位 Inbox)
    PluginsView        插件列表/启停/安装/依赖/导出
    SettingsView       设置(各面板：备份/日志/导航/主题/更新)
    FloatApp           桌面浮窗(内容=某插件自带前端)
  components/          通用部件(与业务无关)
    TopBar / Sidebar / StatusBar / ConfirmDialog / PromptDialog / Icon ...
    PluginUiView       ★插件自带前端挂载器(读入口→Blob→api 桥)
    PluginCard         插件卡片(启停/重载/依赖/导出)
  themes/              主题系统(tokens 推导/皮肤插件)
  styles/              tokens.css(设计令牌) + shell/plugins/settings/float/base
```

## 3. 前端 ↔ Rust：一条 `invoke` 链路（重点）
```
组件   api.pluginsList()                        [src/core/api.ts]
        invoke("plugins_list")                  [@tauri-apps/api/core]
          → Rust generate_handler![plugins::commands::plugins_list]  [src-tauri/src/lib.rs]
          → PluginManager::list()               [src-tauri/src/plugins/manager.rs]
          → serde_json 结果(与 PluginInfo 接口对应)
```
- `api.ts` 的**每个导出函数都对应一个 Rust 命令**，参数名与 Rust `#[tauri::command]` 形参对应(serde camelCase)。
- 类型(`PluginInfo/FileEntry/...`)与 Rust `PluginInfo` 等 `Serialize` 结构一一对应——改后端别忘同步前端类型。

## 4. 插件界面怎么挂进来（重点，`pluginRuntime.ts` + `PluginUiView.vue`）
1. `PluginUiView`(或浮窗)拿到插件 `ui` 入口路径。
2. `plugins_read_file` 读入口 JS 文本。
3. 用 **Blob URL `<script>` 注入**执行（`CSP script-src blob:` 允许；**不能用 `new Function`**——打包版 CSP 拦 eval）。
4. 插件顶层代码执行：注册命令(`api.app.registerCommand`) / 注册 `__TB_PLUGIN_UI__[id]`。
5. 宿主注入**统一 api 桥** `buildBridgeApi`：`call`(→`plugin_call`：native→FFI / process→JSON-RPC)、
   `on`(订阅 `plugin-event`)、`log`(宿主日志)、`context`(vault)、`nav`/`host`。

三种运行时一句话：
- **webview**：入口 JS 注入主进程前端，命令在本地注册表。
- **process**：命令经 `plugins_invoke` → JSON-RPC 到 Python 子进程。
- **native**：命令经 FFI `tb_call` 到 DLL。

---

## 5. 状态管理：模块级单例 + `watch`
- `src/core/plugins.ts`、`vault.ts` 用 `reactive` 做**模块级单例 store**（不用 Pinia），
  组件 `import { pluginState } from ...` 直接订阅。
- `watch(vaultState.path, immediate)`：切工作区时自动刷新插件列表/搜索/主题。
- 对应 React 版：`useState→reactive`、`useRef→模块级 Map`、`useEffect→watch`。

---

## 6. 主题系统（`src/styles/tokens.css` + `src/themes/themes.ts`）
- `tokens.css` 定义**设计令牌**（`--bg/--fg/--accent/...`），暗/亮靠根元素 `[data-theme]` 切换一组值。
- 插件主题包：`PluginThemeDecl { base, tokens, css, preview }` → `setPluginThemes` 把令牌注入 CSS 变量，
  主题插件启用后并入主题选择器。
- 组件/插件 UI 都引用令牌变量，主题切换自动跟随——**不要写死颜色**。

---

## 7. 建议阅读顺序
1. `src/core/api.ts`（一屏看懂前端能用哪些命令/类型）。
2. `src/core/pluginRuntime.ts`（插件运行时三件套，最难也最关键）。
3. `src/core/plugins.ts`（插件 store）。
4. `src/App.vue`（外壳 + 视图注册 + 动态路由）。
5. `src/components/PluginUiView.vue` + `src/views/PluginsView.vue`（插件界面与列表）。
6. `src/styles/tokens.css`（令牌）+ `src/themes/themes.ts`（主题）。

> 启动：`pnpm tauri dev`（宿主 shell 起 dev server + Rust）；改前端代码热更新，改 Rust 需重编。
