# ToolBox 宿主架构 — 学习导言

> 宿主 = `src-tauri/`（Rust，Tauri 2） + `src/`（Vue 3 前端）。
> 本文讲"宿主怎么把插件系统、文件/搜索/备份等服务搭起来"，帮助定位源码。

---

## 1. 一句话
宿主是一个 **Tauri 2 桌面应用**：Rust 主进程负责系统能力（文件/搜索/备份/托盘/窗口/插件），
前端 Vue 3 通过 `invoke` 调 Rust 命令；**业务功能全部插件化**，宿主只留一个教学示例
`core-example` 与真实算法插件 `probe-rat-layer`。

---

## 2. 目录地图

```
src-tauri/
  src/lib.rs            启动：注册插件/命令、setup(日志/托盘/浮窗/备份线程)
  src/main.rs           入口
  src/core/             宿主核心服务（与插件无关，也可被插件核心 API 复用）
    files.rs            文件服务（工作区内列/读/写/增删改/移动/复制）
    input.rs            文件输入(Inbox，数据根/Input) 目录命令
    vault.rs            单工作区路径（旧模型退路）
    workspaces.rs       多工作区（root.json：根 + 当前工作区）
    search.rs           全文搜索（SQLite FTS5 trigram + 拼音）
    backup.rs           备份（原子快照 + 恢复）
    app.rs              应用设置/托盘/窗口/浮窗
    config.rs           配置导入/导出
    path.rs             路径工具（strip_verbatim 等）
    log.rs              日志（按天落盘 + 级别）
  src/plugins/          插件系统
    manager.rs          PluginManager（扫描/启停/卸载/部署/导出/权限门）
    manifest.rs         plugin.json 解析 + KNOWN_PERMISSIONS
    process.rs          process 运行时：spawn 子进程 + JSON-RPC over stdio + 核心 API(clipboard/http/shell/open/log/notify)
    native.rs           native 运行时：libloading 加载 cdylib + C ABI 回调(emit/log/open_path)
    pyruntime.rs        捆绑 Python 运行时解析
    deps.rs             插件依赖安装(pip)
    commands.rs         宿主暴露给前端的 tauri 命令(plugins_*)
    events.rs           事件桥(进程插件 → front-end plugin-event)
  src/rpc/mod.rs        JSON-RPC(进程插件协议) 编解码
```

## 3. 插件系统：三种运行时 + 统一清单

插件有 **webview / process / native** 三种运行时，共享一个 `plugin.json` 清单。

### 3.1 清单 `plugin.json`（`plugins/manifest.rs`）
声明：`id`、`name`、`runtime`、`entry`/`main`、`commands`、`events`、`theme`、`actions`(topbar/tray/file)、
`settings`、`permissions`(向宿主申请的权限：`clipboard/http/shell/open/notify/log`…)。
- `KNOWN_PERMISSIONS` 是**白名单**：声明了但不在清单里的权限会被拒（粗粒度沙箱的第一步）。

### 3.2 process 运行时（`plugins/process.rs`）
- 宿主 `spawn` 一个子进程（被捆绑的 Python 或外部解释器），**JSON-RPC over stdio**（`rpc/mod.rs`）。
- 每消息一行 JSON（request/response/notification），`MAX_LINE_BYTES` 防超长行；超时/stderr tail 诊断。
- **核心 API**（插件可调、宿主实现）：
  - `fs.readText/writeText/listDir`（限工作区/输入目录，`resolve_read` 只读）
  - `open`(tauri-plugin-opener)、`clipboard.read/write`(tauri-plugin-clipboard-manager)
  - `http.request`(reqwest，4MB 上限)、`shell.exec`(tauri-plugin-shell，输出写缓存文件+40行尾)
  - `log`(宿主日志)、`notify`(前端横幅)
- 权限门在 `handle_core_request`：方法 → 所需权限 → 校验插件 `permissions`。

### 3.3 native 运行时（`plugins/native.rs` + `tb-sdk`）
- 加载编译好的 **cdylib DLL**（如 `tb_probe_rat_layer.dll`）via `libloading`。
- **C ABI**：`tb_plugin!` 宏生成 `tb_abi_version/tb_create/tb_call/tb_free_string/tb_destroy`；
  宿主传 `TbHostApi`（含 `emit_event/log/open_path` 回调）→ 插件用 `tb_sdk` 发事件/日志/打开文件。
- 安全：核心插件是**信任代码**（`catch_unwind` 隔离 panic），不做沙箱；需**全量重启应用**才能热替换 DLL。

### 3.4 PluginManager（`plugins/manager.rs`）
- `ensure_refreshed` 快照检测→扫描插件目录；`ensure_core_plugins/ensure_bundled_plugins` 部署；
  `export_zip` 导出；`KNOWN_PERMISSIONS` 校验。
- 插件状态在 `plugins.json`（`%APPDATA%\com.toolbox.desktop\plugins.json`），默认全关，
  `probe-rat-layer`（native 核心）默认启用。

## 4. 命令与数据流（前端 ↔ Rust）

```
Vue 组件  invoke("plugins_list")  →  lib.rs::generate_handler![plugins::commands::plugins_list]
          →  PluginManager::list()  →  serde_json 返回
插件 UI   在 PluginUiView 里用 api.call("layer.config", {...})
          → 宿主 plugin_call → NativePlugin::call(method, params) → tb_call(handle,...) → 插件 JSON
事件      进程插件 → host_emit_event → 宿主 "plugin-event" 事件 → 前端 api.on("event")
```

- 宿主命令注册在 `lib.rs::run` 的 `generate_handler![...]`（按域组织：core/*、plugins/commands）。
- `PluginManager` 存在 `State<Mutex<...>>`，命令取 `state.lock()`。

---

## 5. 宿主核心服务（`src/core/*`）
- **数据根模型**：所有数据在一个自选"数据根"（如 `D:\ToolBoxData`），
  `Project/<名称>` = 工作区（`root.json` 记 根+当前）；`Input/` = 文件输入(Inbox)。
- **文件服务**（`files.rs`）：限定在工作区（`path_within` 组件边界判定 + 去 `\\?\` 前缀 + 大小写不敏感），
  隐藏 `.toolbox` 过滤；被宿主与插件"核心 API"共用。
- **搜索**（`search.rs`）：SQLite FTS5 trigram 增量索引，文件名优先 + 短词 LIKE 兜底 + 拼音(首字母/全拼)。
- **备份**（`backup.rs`）：vault 快照原子提交 + 恢复；后台线程自动备份。
- **日志**（`log.rs`）：`%APPDATA%/com.toolbox.desktop/logs/` 按天落盘，级别可调，应用内查看器。

---

## 6. 建议阅读顺序
1. `src-tauri/src/lib.rs::run`（一屏看懂注册了哪些插件/命令/Setup 做了什么）。
2. `plugins/manifest.rs`（清单字段 + `KNOWN_PERMISSIONS`）。
3. `plugins/native.rs` + `tb-sdk/src/lib.rs`（native 插件 C ABI 协议）。
4. `plugins/process.rs`（process 运行时 + 核心 API）。
5. `plugins/manager.rs`（插件生命周期大管家）。
6. `core/*`（文件/工作区/搜索/备份）。

> 想验证：`pnpm tauri dev` 边看日志边点插件；`plugins/py-tools`、`plugins/hello-tb`、
> `core-plugins/probe-rat-layer` 是三种运行时的最佳范例。
