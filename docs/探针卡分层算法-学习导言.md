# 探针卡分层算法 — 学习导言

> 插件：`core-plugins/probe-rat-layer`（native cdylib，随宿主分发）。
> 目的：把 Allegro 导出的**飞线(pin 坐标)**按规则分到若干**布线层**，产出 `layer_N.lst` 供 Allegro 导入。
> 本文从"整条流水线在讲什么"讲到"每个模块/每个旋钮在干什么"，帮助阅读源码。

---

## 1. 一句话
给定一堆线（每根线是两个 pin 之间的连线段），要把每根线**放到某一层**，使得：
- 同层相邻的线不产生**硬冲突**（不同 net 的线不能在任何层上靠得太近/交叉成致命）；
- 每层不会**超容**（圆心等密集区占用 ≤ 层容量，否则剩下"走不通/需人工"）；
- **交叉尽量少**（同层交叉影响制造良率）；
- 最后给出每层信息 + 可布性统计（走通率）。

这是一个典型的**层分配(layer assignment) + 拥塞/交叉双目标优化**问题。

---

## 2. 整条流水线（推荐先读这个）

```
load_input(读入数据)                 [io/*]
   → 解析 Allegro 1.xlsx + 筛选(pin表) + 生成 wire(线段)
电源/地分离                          [layer_stack::split_trace_plane]
   → 区分"信号 trace(要分层布线)" vs "平面/电源地(不分层)"
构建拥塞图                           [congestion::build_congestion_map]
   → 把每条线栅格化到网格，算每格 occupancy = demand / supply
冲突检测                             [conflict_classifier::detect_all_conflicts]
   → 找出几何上可能冲突的"线对"；标成硬 / 软
分层/分组                            [layer_packing::pack_layers]
   → 扇区轮询把线放进允许层，尽量满足硬冲突约束 + 层容量
贪心交叉最小化                        [layer_packing::minimize_crossings]
   → 在同层软冲突线对间交换层，减少同层交叉
模拟退火精修                          [optimizer::optimize_layering]
   → 以"软交叉 + 层均衡护栏"为代价，随机交换/移动线，用温度退火逼近更优
后处理                               [post_process]
   → 硬冲突兜底(需人工)、按层统计软冲突/占用、走通率(直线/路径/洪泛)
拥塞均衡(可选, 默认关)                 [post_process::congestion_balance]
   → 把超容格点/层上的线挪到低拥塞允许层，摊平圆心占用峰值
导出结果用 report + 渲染              [report/*, viz/*]
   → 生成 layer_N.lst / 统计 / 走通率 / PNG
```

**模块地图**（`src/` 下每个文件管什么）：

| 文件 | 角色 |
|---|---|
| `io/*` | 读 Allegro xlsx + 筛选，生成 `net/wire/pin/keepout/signal_group` 数据模型 |

| `geometry.rs` | 几何工具：线段相交、距离、曼哈顿/路径估计 |
| `congestion.rs` | 拥塞网格：`occupancy = demand/supply`，`rasterize` 线到格点 |
| `conflict_classifier.rs` | 检测候选"冲突线对"：硬/软判定（顶阈值/pin 邻近/短线容忍） |

## 3. 核心概念（看懂这个就懂了 80%）

### 3.1 数据模型
- `Net`：一个网络（如一根 AK4075 信号），由 1 或多个 `Pin` 组成；`pin` 是端点。
- `Wire`：一段要布的线（`start/end` 两 pin），带 `width`(线径) 与 `clearance`(线距)。**本数据是 2-pin 放射状**：每 net 只 1 段。
- `KeepoutZone`：禁布区（矩形/圆），该格点 `supply=0`。
- `SignalGroup`：信号组（同组可互换/有相同允许层规则）。
- `LayerStack`：层定义（index/kind(signal|plane)/preferred_dir）。`preferred_dir` 影响走线方向与可布性估算。

### 3.2 拥塞网格 `occupancy = demand / supply`（`congestion.rs`）
- **`cell`**：网格边长（`congestion_grid_cell`，DC/HV 用 2.0，全量 0.5）。
- **`demand`**：每格 `Σ (线宽+线距) × congestion_demand_factor`（把线 rasterize 到格点，用 `_wire_cells` 采样）。
- **`supply`**：基础为 `cell`，再扣**禁布区**（keepout→supply=0）、**过孔预留**（×`1-via_area_cost`）、**引脚密度**（pin 处 ×`1/pin_density_weight`）。
- 逐格 `occupancy = demand / supply`。`occupancy > layer_capacity` 即"超容"（这一层在这里塞不下）。

### 3.3 冲突检测（`conflict_classifier`）
几何上会打到的「线对」先进入候选（bbox 扫描线 O(n log n + k)），再判定级别：
- **硬冲突(Hard)**：交点拥塞 ≥ `congestion_hard_threshold`，**且**插端点对距离 < `max(线宽)`（pin 邻近）等；判硬 = **不能同层**，否则留人工。
- **软冲突(Soft)**：交叉可容忍，同层会交叉但不算致命——目标是**尽量让它们不同层/减交叉**。
- **短线容忍**：若某段 ≤ `short_segment_len`，其硬阈值按 `short_segment_crossing_factor` 放大（默认关闭，`crossing_hotspot_short` 原因）。

### 3.4 分层（`layer_packing::pack_layers`）
- 每根线有**允许层集合**（`wire_allowed_layers`，按信号组/preferred_dir/平面排除）。
- **扇区轮询**：把线按方向分"扇区"，轮询地往允许层塞，尽量满足硬冲突 + 层容量；`capacity_lower_bound` 给出理论下界。
- **DSatur**（`method=dsatur`）：图着色基线，只作对比。

### 3.5 模拟退火（`optimizer`）
- **邻域**：`try_swap`（交换两根线的层）、`try_move`（挪一根线），都先查目标层**硬冲突**（`hard_conflict_in`，O(deg) 邻接表）。
- **代价**：`soft_crossings`（同层软交叉数）+ **层均衡护栏**（count/长度/扇区不均衡 ≤ slack）。**注意：代价没直接管"拥塞"**——所以有时初始分组定的 1.78 峰值 SA 不动它。
- **温度/冷却/重启**：`sa_initial_temp`、`sa_cooling`、`sa_restarts`；`sa_max_steps=0` 自动。**`sa_max_steps` 调大反而更差**（实测）——别拉满。

### 3.6 走通率（可布性诊断，`post_process`）
- **直线**：分配到该层后，直线路径占用峰值 ≤ `layer_capacity` 才可布。
- **路径**：按 `preferred_dir` 生成曼哈顿 L/Z 估计路径，判占用 ≤ 容量——更真实。
- **洪泛(真实可布)**：层内"容量内可走"格点做**连通分量洪泛**，判 net 的线端是否落在同一连通可布区——能体现"可绕行"，比直线/路径更诚实（本数据 98%→100%）。

### 3.7 拥塞均衡（`post_process::congestion_balance`，默认关）
- 对超容格点/层上的线做**贪心移动**到低拥塞允许层（不新增硬冲突、只做"净溢出减小"）。
- **拥塞+交叉感知**：移动判据 = 溢出增量 + `congestion_balance_cross_weight`×同层交叉增量。
- 实测把圆心占用峰值 **1.56→1.11**、走通率(洪泛)→**100%**，交叉不回升。

## 4. 配置旋钮速查（节选；完整见 `config.rs`）

| 旋钮 | 作用 | 默认 | 推荐 |
|---|---|---|---|
| `method` | packing(扇区轮询)/dsatur(着色) | packing | packing |
| `optimizer` | sa/greedy/none | sa | sa |
| `resolve_conflict_rounds` | 硬冲突微调轮数 | 12 | 12–16 |
| `minimize_crossings_passes` | 贪心交叉轮数 | 6 | 6–10 |
| `sa_restarts` | 模拟退火重启 | 2 | 2–5 |
| `sa_initial_temp` / `sa_cooling` | 退火温度/冷却 | 8 / 0.9995 | 默认 |
| `congestion_grid_cell` | 拥塞网格边长 | 2.0(UI) | DC/HV 2.0, 全量 0.5 |
| `congestion_hard_threshold` | 硬阈值(越大越宽松) | 0.8 | DC/HV 3.0 |
| `layer_capacity` | 每层占用上限 | 1.0 | ≤1.0 |
| `congestion_k` | 拥塞平滑代价指数 | 2.0 | 2.0 |
| `short_segment_len` / `short_segment_crossing_factor` | 短线容忍 | 0 / 1.0 | 需时 5–10mm / 1.5–3 |
| `congestion_balance` / `congestion_balance_passes` / `congestion_balance_cross_weight` | 拥塞均衡 | false / 20 / 0.5 | DC/HV 建议开 |
| `sa_max_steps` | SA 步数(0=自动) | 0 | **勿调大**(实测更差) |

## 5. 常见问题 / 坑（阅读源码前先有这个认知）
- **圆心拥塞有几何下限**：本数据 2-pin 放射状，每根线在分配层**必穿圆心**。分层只能把峰值**摊平**(1.56→1.11)，**无法单靠分层降到 ≤1.0**——需加层数或过孔 fan-out(布线级)。
- **"几何交叉数"固定不变**：`soft_conflicts`(23824)是所有线几何交叉对数，与分层无关；只有**同层交叉**(~2100)可被 SA/均衡优化，且接近下限。
- **结果随机**：曾因 `HashMap` 随机迭代序导致每次不同；现用 `FxHashMap`(`collections.rs`)**确定性哈希**，同配置每次结果一致。
- **`sa_max_steps` 调大反而更差**：SA 步数多后陷入更差局部 + 需人工变多，勿拉满。
- **跨层/过孔/拓扑改进**：只对**含多段网的板**有意义；本 2-pin 数据上里程碑 0/1/2 均验证"无收益"。
