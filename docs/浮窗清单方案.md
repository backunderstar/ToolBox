# 桌面半透明浮窗清单 —— 方案计划

> 状态：方案待确认（未实施）
> 关联需求：#5「除了应用内的清单页，固定一个半透明窗格放在桌面上，便捷增加/管理待做事项、清单」

---

## 1. 需求理解

在 ToolBox 主窗口之外，桌面上常驻一个**小型半透明窗格**：

- 置顶显示（不被其他窗口遮挡，类似便签/桌面小组件）
- 半透明、无边框、可拖拽、可记忆位置
- 打开应用即可用，快捷**添加 / 勾选完成 / 删除**待办
- 数据与主应用共享（纯文件优先，可备份、可迁移）

预期交互形态：

```
┌──────────────────────────┐
│ 快速待办          ➕      │  ← 标题行（可拖拽）
├──────────────────────────┤
│ ☐ 写周报                 │
│ ☑ 提交报销   ✔           │
│ ☐ 预约体检   ✔           │  ← 半透明毛玻璃质感
├──────────────────────────┤
│ [+ 添加待办…]             │
└──────────────────────────┘
```

## 2. 技术选型调研

### 2.1 方案对比

| 方案 | 说明 | 结论 |
|---|---|---|
| **Tauri 第二个窗口（推荐）** | 同一进程内创建独立 WebView 窗口，`transparent` + `alwaysOnTop` + `decorations: false` | ✅ 复用现有 Rust 核心、插件系统、文件读写逻辑，成本最低 |
| 独立小进程（如 Python/Electron） | 单独打包一个桌面便签程序 | ❌ 双份运行时、数据同步复杂、违背"一个 ToolBox" |
| 系统级桌面小组件（Win11 Widgets） | 微软官方小组件框架 | ❌ 仅 Win11、开发栈不通用、数据受沙盒限制 |

**结论：Tauri 2 多窗口**。主窗口与浮窗同进程，天然共享 Rust 状态与文件访问。

### 2.2 Tauri 2 多窗口创建方式

两种方式，推荐**运行时创建**（主窗口启动时 `setup` 里用 Rust 创建，可编程控制）：

```rust
// src-tauri/src/window.rs（示意）
use tauri::{WebviewWindowBuilder, WebviewUrl};

pub fn create_float_window(app: &tauri::AppHandle) -> tauri::Result<()> {
    let win = WebviewWindowBuilder::new(app, "float", WebviewUrl::App("float".into()))
        .title("ToolBox 快速待办")
        .inner_size(280.0, 420.0)
        .transparent(true)          // 半透明
        .decorations(false)         // 无边框
        .always_on_top(true)        // 置顶
        .skip_taskbar(true)         // 不进任务栏
        .resizable(true)
        .build()?;
    Ok(())
}
```

前端侧也可 `new WebviewWindow(...)`（@tauri-apps/api/webviewWindow），但 Rust 侧创建能拿到 `WebviewWindow` 句柄做更多控制（显隐、置顶切换）。

### 2.3 关键能力与对应实现

| 需求 | 实现方式 | 说明 |
|---|---|---|
| 半透明 | 窗口 `transparent: true` + CSS 背景 `rgba()` / `backdrop-filter: blur()` | ⚠️ Windows 兼容性见 §6 风险 |
| 无边框 | `decorations: false` | 需要自己实现拖拽（见下）与关闭按钮 |
| 置顶 | `alwaysOnTop: true`，可运行时 `set_always_on_top(false)` 切换 | 提供"取消置顶"开关避免遮挡全屏应用 |
| 拖拽移动 | 标题栏元素加 `data-tauri-drag-region`（Tauri 2 内置） | 无需额外依赖 |
| 位置/大小记忆 | **tauri-plugin-window-state**（官方插件） | 自动保存/恢复位置大小；也可自存 vault 内 |
| 显示/隐藏 | `window.show() / hide()`（保留状态，不销毁重建） | 配托盘或快捷键（如 `Ctrl+Shift+T`） |
| 托盘 | tauri-plugin-tray-icon | 可选：右键菜单"显示/隐藏浮窗/退出" |
| 开机自启 | tauri-plugin-autostart | 可选：开机自动拉起浮窗 |
| 数据同步 | **共享文件 + Tauri 事件** | 见 §3 |

## 3. 数据模型与架构设计

### 3.1 数据模型（延续"纯文件优先"）

新增 `vault/data/todos/todos.json`（与 checklists 并列）：

```json
{
  "version": 1,
  "items": [
    {
      "id": "t_8f3a",
      "text": "写周报",
      "done": false,
      "createdAt": "2026-01-15T09:30:00+08:00",
      "doneAt": null
    }
  ]
}
```

> **待确认 A**：浮窗是独立的轻量"快速待办"（todos.json），还是复用现有「清单」（data/checklists/*.json）？
> - 方案 A1（推荐）：独立 todos——浮窗追求极简，不与清单的条目/说明/引用等复杂结构耦合
> - 方案 A2：复用清单——浮窗显示"某个清单"的内容，天然与主应用一致，但浮窗 UI 要做清单选择

### 3.2 Rust 侧（新模块 `src-tauri/src/core/todos.rs`）

- 命令：`todos_list / todos_add / todos_toggle / todos_delete / todos_update`
- 文件读写走现有 `resolve_safe` 路径校验；写盘即真源
- 每次变更后 `app.emit("todos-changed", ...)` 广播给**所有窗口**

### 3.3 前端

- 主窗口与浮窗各自维护 React 状态，**以文件为唯一真源**：
  - 变更流程：任意窗口操作 → invoke Rust 命令 → 写盘 → emit 事件 → 所有窗口刷新
  - 避免"双窗口各改各的"冲突（同一进程内 Rust 侧可加 `Mutex` 串行化写盘）
- 新增浮窗页面：`src/float/`（独立 React 入口或同一入口按路由分支），组件极简：
  `FloatApp → TodoList + TodoItem + TodoInput + 拖拽标题栏`
- 浮窗 UI 样式走现有主题令牌（tokens.css），半透明层用 `rgba(--bg-*, 0.85)` + 可选 `backdrop-filter`

### 3.4 主窗口联动（可选增强）

- 主应用「清单/待办」页可直接看到/编辑同一份 todos.json
- 浮窗双击某项 → 事件通知主窗口打开详情（低优先级）

## 5. 分阶段实施计划

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **M-A 窗口骨架** | 创建浮窗（透明/无边框/置顶/拖拽/位置记忆），空 UI | 真机上浮窗可拖拽、位置重启后恢复、置顶生效 |
| **M-B 数据闭环** | todos.json + 5 条 Rust 命令 + 浮窗 CRUD UI（添加/勾选/删除） | 浮窗内增删改后文件正确落盘 |
| **M-C 双窗联动** | emit/listen 事件同步；主窗口"待办"入口展示同一数据 | 浮窗改 → 主窗口立即刷新（反向同理） |
| **M-D 打磨发布** | 托盘/快捷键显隐、开机自启开关、置顶开关、透明度主题适配、E2E 验证 | 完整使用流程跑通，与现有清单/记录不冲突 |

每阶段遵循既有验证纪律：`cargo test` + `pnpm build` + 真实 WebView2 E2E（CDP 9226）+ 提交。

## 6. 风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| **Windows 透明窗口兼容性** | Win10 部分环境 `transparent: true` 出现黑底/不透明；已知 issue [#8133](https://github.com/tauri-apps/tauri/issues/8133)、[#13270](https://github.com/tauri-apps/tauri/issues/13270) | 降级策略：检测到不透明时用"深色圆角卡片"样式兜底；Win11 可用 window-vibrancy 亚克力 |
| 置顶遮挡 | 全屏游戏/演示时浮窗盖住内容 | 设置页提供"取消置顶"；托盘菜单快捷切换 |
| 多窗口状态不一致 | 两个 WebView 的 localStorage 不共享 | 状态只走 IPC + 文件，不用 localStorage 存业务数据 |
| 拖拽与点击冲突 | 无边框窗口拖拽区域误触 | 仅标题栏标记 `data-tauri-drag-region`，列表区正常交互 |
| 浮窗误关 | 用户点 X 后找不回来 | 关闭=隐藏（hide 而非 destroy），托盘/快捷键重新唤起 |
